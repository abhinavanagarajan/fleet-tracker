Suggested 8-minute flow

  1. Health - show real MongoDB + Redis versions, 150 logs, 5 indexes. Click consistency check → CONSISTENT.
  2. Dashboard - leaderboard comes from Redis (note ms), recent logs from MongoDB. Explain the hybrid design.
  3. Submit Shift - pick a bus, click Auto-fill demo values, save. Point at the trace panel (Mongo upsert, then HINCRBYFLOAT / ZADD). Watch the leaderboard update.
  4. Logs → open the new log - push a late single (embedded array, $push), show recalculated totals; then delete it and show Redis reverse.
  5. Query Console - Run all. Dwell on Q2 (anomaly), Q4 (Sunday vs weekday), Q5 ($unwind), Q9/Q10 (Redis).
  6. Index Lab - explain plans (IXSCAN vs COLLSCAN), then the 100k-document benchmark.
  7. Redis Explorer - show the three structures. Failure demo: stop Redis, reload Dashboard → it falls back to MongoDB; start Redis, Rebuild Redis.
